Key Terms in This Domain

  • AWS Well-Architected Tool: Self-assessment against the AWS Well-Architected Framework pillars
  • AWS Elastic Beanstalk: Deploy and run web apps on AWS without managing infrastructure (PaaS)
  • AWS Outposts: Run AWS infrastructure on-premises in your own data center
  • Amazon DynamoDB: Managed NoSQL key-value and document database with single-digit-ms latency
  • AWS CloudFormation: Infrastructure-as-code: provision AWS resources from templates
  • AWS Systems Manager: Operational hub: patch, automate, and configure AWS and on-prem resources
  • AWS Application Discovery Service: Discover on-premises servers and dependencies for migration planning
  • AWS Application Migration Service: Lift-and-shift migrate servers to AWS with minimal downtime
  • AWS DMS: Database Migration Service: migrate databases to AWS with minimal downtime
  • Migration Evaluator: Build a data-driven business case for AWS migration
