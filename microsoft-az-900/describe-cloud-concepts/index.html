Sample Questions

A new Azure user needs to identify the right concept for cloud computing definition. Which answer should they choose?

Answer: Delivery of computing services over the internet, including compute, storage, networking, and applications

Cloud computing provides IT services through internet-accessible platforms instead of requiring every resource to be owned and operated locally.

An IT manager asks how cloud computing definition applies to Azure. Which explanation is most accurate?

Answer: A way to use scalable IT services without building and operating every physical datacenter component

Cloud computing lets organizations use scalable services while reducing direct responsibility for physical facilities.

A company is learning basic Azure concepts. Which statement best describes shared responsibility model?

Answer: In IaaS, customers manage more of the operating system and application stack than in PaaS or SaaS

IaaS gives customers more control and therefore more responsibility for the software stack.
