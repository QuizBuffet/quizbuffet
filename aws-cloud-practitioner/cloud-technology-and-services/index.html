Key Terms in This Domain

  • AWS CloudFormation: Infrastructure-as-code: provision AWS resources from templates
  • AWS Management Console: Web-based UI for managing AWS services
  • AWS Elastic Beanstalk: Deploy and run web apps on AWS without managing infrastructure (PaaS)
  • AWS Outposts: Run AWS infrastructure on-premises in your own data center
  • Amazon Aurora: High-performance MySQL- and PostgreSQL-compatible managed relational database
  • AWS CodeBuild: Managed build service for compiling, testing, and packaging code
  • AWS CodePipeline: Fully managed CI/CD pipeline orchestration
  • Amazon SageMaker AI: End-to-end platform to build, train, and deploy ML models
  • AWS Control Tower: Set up and govern a secure, multi-account AWS environment
  • AWS Organizations: Centrally manage and govern multiple AWS accounts with consolidated billing
