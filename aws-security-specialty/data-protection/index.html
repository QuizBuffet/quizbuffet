Sample Questions

A public ALB must reject clients that use obsolete TLS versions while preserving HTTPS for modern browsers. What should the security engineer configure?

Answer: An ELB security policy that permits only approved TLS versions and ciphers

ELB security policies define the TLS protocol and cipher suites used by HTTPS listeners.

A company wants end users to know they are connecting to the intended public application domain. What data-in-transit control is required?

Answer: A trusted public certificate on the HTTPS endpoint that matches the application domain

A valid certificate lets clients authenticate the endpoint and establish an encrypted session.

A service mesh in Kubernetes must encrypt service-to-service calls between pods. Which control aligns with the requirement?

Answer: Use mutual TLS between services with managed certificate rotation

Mutual TLS encrypts traffic and authenticates services on both sides of the connection.
