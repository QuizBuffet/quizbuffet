Sample Questions

A CloudOps engineer must collect application latency metrics from an EC2-hosted service and retain API activity history for incident investigations. Which combination should the engineer configure?
  • A. Amazon CloudWatch metrics for latency and AWS CloudTrail trails for API activity
  • B. AWS Config rules for latency and Amazon S3 access logs for API activity
  • C. Amazon Managed Service for Prometheus for API audit history and AWS CloudTrail Lake for latency metrics
  • D. AWS Systems Manager Inventory for latency and Amazon EventBridge archives for API activity

CloudWatch and CloudTrail configuration is best addressed by Amazon CloudWatch metrics for latency and AWS CloudTrail trails for API activity, because it matches the operational requirement in the scenario. This is the correct answer.

A workload owner needs a dashboard that combines Lambda error metrics, ALB target response times, and RDS CPU metrics. Which service should be the primary visualization layer?
  • D. Amazon CloudWatch dashboards
  • A. AWS CloudTrail event history
  • B. AWS Cost Explorer reports
  • C. AWS Systems Manager Patch Manager

CloudWatch and CloudTrail configuration is best addressed by Amazon CloudWatch dashboards, because it matches the operational requirement in the scenario. This is the correct answer.

A team needs centralized visibility into container metrics from ECS tasks and Kubernetes-style metrics from EKS workloads. Which service pairing should be prioritized?
  • B. Amazon CloudWatch Container Insights and Amazon Managed Service for Prometheus
  • A. AWS CloudTrail Insights and Amazon S3 Storage Lens
  • C. AWS Config aggregators and AWS Trusted Advisor
  • D. Amazon Athena and AWS Cost Explorer

CloudWatch and CloudTrail configuration is best addressed by Amazon CloudWatch Container Insights and Amazon Managed Service for Prometheus, because it matches the operational requirement in the scenario. This is the correct answer.

A regulated application must retain a record of IAM API calls across all Regions. Which configuration is most appropriate?
  • A. Create a multi-Region AWS CloudTrail trail and store the logs in an S3 bucket
  • B. Create a CloudWatch alarm for IAM changes without retaining logs
  • C. Enable VPC Flow Logs for every subnet
  • D. Enable Amazon RDS Performance Insights

CloudWatch and CloudTrail configuration is best addressed by Create a multi-Region AWS CloudTrail trail and store the logs in an S3 bucket, because it matches the operational requirement in the scenario. This is the correct answer.

A platform team needs Prometheus-compatible metrics for EKS workloads without managing Prometheus servers. Which service should be selected?
  • D. Amazon Managed Service for Prometheus
  • A. AWS Config advanced queries
  • B. Amazon S3 Inventory
  • C. AWS Backup Audit Manager

CloudWatch and CloudTrail configuration is best addressed by Amazon Managed Service for Prometheus, because it matches the operational requirement in the scenario. This is the correct answer.

An operations team wants to detect unauthorized changes to security groups and also monitor CPUUtilization for EC2 instances. Which approach meets both needs?
  • C. Use AWS CloudTrail for security group API events and Amazon CloudWatch metrics for CPUUtilization
  • A. Use Amazon Inspector for security group API events and AWS Backup for CPUUtilization
  • B. Use AWS X-Ray for security group API events and AWS Config only for CPUUtilization
  • D. Use Amazon VPC Flow Logs for security group API events and Amazon CloudFront logs for CPUUtilization

CloudWatch and CloudTrail configuration is best addressed by Use AWS CloudTrail for security group API events and Amazon CloudWatch metrics for CPUUtilization, because it matches the operational requirement in the scenario. This is the correct answer.

A CloudOps engineer needs to query historical CloudTrail events for troubleshooting access changes without building a custom query platform. What should the engineer use?
  • B. AWS CloudTrail Lake
  • A. Amazon EFS lifecycle management
  • C. EC2 detailed monitoring
  • D. Amazon CloudFront standard logs

CloudWatch and CloudTrail configuration is best addressed by AWS CloudTrail Lake, because it matches the operational requirement in the scenario. This is the correct answer.

An application emits custom business metrics from EC2. The operations team wants the metrics available for alarms and dashboards. Which API should the application use?
  • C. PutMetricData to publish custom metrics to Amazon CloudWatch
  • A. PutObject to write metrics to an S3 bucket only
  • B. StartLogging to create a CloudTrail trail for the application metrics
  • D. CreateSnapshot to capture the metrics from the EBS volume

CloudWatch and CloudTrail configuration is best addressed by PutMetricData to publish custom metrics to Amazon CloudWatch, because it matches the operational requirement in the scenario. This is the correct answer.

Key Terms in This Domain

  • Amazon CloudWatch: Metrics, logs, dashboards, and alarms for AWS resources
  • CloudWatch dashboards: Customizable, shareable views of metrics and alarms across accounts and Regions
  • CloudWatch agent: Collects custom metrics and OS-level logs from EC2, ECS, and EKS
  • CloudWatch alarms: Trigger actions when metrics cross thresholds
  • CloudWatch composite alarms: Combine multiple alarms into a single state to reduce noise
  • Amazon Managed Grafana: Fully managed Grafana for metrics dashboards
  • Amazon EventBridge: Serverless event bus that routes, enriches, and delivers events
  • Amazon RDS Performance Insights: Database performance tuning with load and wait analysis
  • Amazon CloudWatch Logs: Centralized log collection, search, and retention
  • Amazon CloudWatch Synthetics: Synthetic canary tests for endpoints and APIs
