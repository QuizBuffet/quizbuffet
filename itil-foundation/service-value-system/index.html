Sample Questions

Which statement best describes the purpose of the ITIL service value system?

Answer: It describes how all components and activities of the organization work together as a system to enable value creation

The service value system shows how organizational components and activities work together to facilitate value creation. This is the correct answer.

Which statement about the ITIL service value system component is CORRECT? How do guiding principles support the service value system?

Answer: They guide decisions and actions across all components and activities of the organization

Guiding principles influence how the organization makes decisions and acts across the SVS. This is the correct answer.

Which statement about the ITIL service value system component is CORRECT? Why is continual improvement included in the service value system?

Answer: To ensure the organization and its services keep improving in alignment with changing needs

Continual improvement supports ongoing improvement of services, practices, and the service value system. This is the correct answer.
