6.0 Security Foundations and Governance — SCS-C03 Practice Quiz

This domain is part of the AWS Certified Security – Specialty practice test. Each question is tagged by exam objective and difficulty so you can drill exactly the areas you need.

Sample Questions

A company is moving from independent AWS accounts to a governed multi-account environment. What should be established first?

Answer: Create an AWS Organizations structure with OUs aligned to security, production, development, and sandbox governance needs

In this scenario, AWS Organizations deployment starts with an OU structure that matches governance boundaries and lets guardrails apply consistently.

A multi-account design uses one account for security tooling and another for log archive. Why is this useful?

Answer: It separates duties and protects audit evidence from workload account administrators

Here, AWS Organizations deployment benefits from specialized accounts that reduce privilege overlap and evidence tampering risk.

A security team wants to enable an optional control that prevents public S3 buckets in governed accounts. What should be used?

Answer: Enable the relevant AWS Control Tower control on the intended OU

AWS Control Tower controls can be applied at OU scope to enforce or detect baseline requirements.
