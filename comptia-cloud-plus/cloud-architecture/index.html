Sample Questions

Which of the following BEST describes Infrastructure as a Service (IaaS)?
  • A. A model where the provider manages everything including the application
  • B. A model that provides virtualized computing resources such as VMs, storage, and networking over the internet
  • C. A model where software is delivered and managed entirely by the provider
  • D. A model that executes code in response to events without managing servers

IaaS provides virtualized infrastructure components, VMs, storage, and networking, while the customer manages the OS and everything above it. This is the correct answer.

Which cloud service model provides a managed platform for developers to build, deploy, and run applications without managing the underlying servers or operating system?
  • A. IaaS
  • B. FaaS
  • C. PaaS
  • D. SaaS

PaaS provides a complete managed platform including runtime, middleware, and OS, so developers only focus on their application code. This is the correct answer.

A startup wants to host a custom web application and requires full control over the operating system, middleware, and runtime. Which cloud service model should they choose?
  • A. SaaS
  • B. PaaS
  • C. IaaS
  • D. FaaS

IaaS gives the customer full control over the OS, middleware, and runtime on top of virtualized infrastructure. This is the correct answer.

A development team wants to deploy a web application quickly without dealing with OS patching, server provisioning, or runtime configuration. Which cloud model is BEST suited for their needs?
  • A. IaaS
  • B. PaaS
  • C. SaaS
  • D. FaaS

PaaS handles OS patching, server provisioning, and runtime, letting the team focus purely on deploying their application code. This is the correct answer.

An organization wants to provide employees with email and collaboration tools without any IT overhead for installation, updates, or server maintenance. Which cloud model is MOST appropriate?
  • A. IaaS
  • B. PaaS
  • C. FaaS
  • D. SaaS

SaaS delivers fully managed, ready-to-use applications over the internet with no installation or maintenance required from the customer. This is the correct answer.

A company migrates to an IaaS cloud model. Which of the following tasks remains the customer's responsibility?
  • A. Physical hardware maintenance
  • B. Hypervisor patching
  • C. Operating system updates and application security
  • D. Data center power and cooling

In IaaS, the customer is responsible for everything from the OS upward, including OS patching and application security. This is the correct answer.

A financial firm needs to run legacy applications that require custom kernel modules and specific OS-level configurations not supported by managed platforms. Which cloud service model provides the MOST flexibility for this requirement?
  • A. SaaS
  • B. PaaS
  • C. FaaS
  • D. IaaS

IaaS gives the customer direct access to virtualized hardware and full OS control, making it ideal for legacy apps requiring custom kernel modules. This is the correct answer.

A company uses a PaaS solution to host their application. A security audit reveals a critical vulnerability in the provider's managed runtime environment. Who is responsible for patching it?
  • A. The customer, since they own the application running on the platform
  • B. Both the customer and provider share equal responsibility
  • C. The cloud provider, since the runtime is part of the managed platform
  • D. A third-party security firm contracted by the customer

In PaaS, the provider manages the runtime, middleware, and OS. Vulnerabilities in those layers are the provider's responsibility to patch. This is the correct answer.
