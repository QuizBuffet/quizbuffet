5.0 Service Value Chain Activities — ITIL 4 Practice Quiz

20 exam-style questions covering 5% of the ITIL 4 exam. Instant feedback on every answer, progress tracking, no signup required.

This domain is part of the ITIL 4 Foundation practice test. Each question is tagged by exam objective and difficulty so you can drill exactly the areas you need.

Sample Questions

Which statement best describes the service value chain?

Answer: An operating model for the creation, delivery, and continual improvement of services

The service value chain is the central operating model for creating, delivering, and continually improving services. This is the correct answer.

Which statement about interconnected nature of the service value chain is CORRECT?

Answer: Different types of demand and opportunity require different combinations of activities

The service value chain is flexible so organizations can create value streams suited to different needs. This is the correct answer.

Identify the missing word(s): The relevant service value chain activity or concept is [?]. Which statement about improve is CORRECT?

Answer: It applies to every service value chain activity, not just to a separate improvement team

Improve is part of the service value chain and can influence all activities and dimensions. This is the correct answer.
