Sample Questions

Which of the following BEST describes a technical security control?

Answer: A hardware or software mechanism — such as a firewall, encryption, or access control list — that enforces security through technology rather than human action or policy

Technical controls are implemented through technology — firewalls, encryption, IDS/IPS, and access control lists all enforce security automatically without relying on human action. This is the correct answer.

Which of the following is the BEST example of a managerial security control?

Answer: Conducting an annual risk assessment to identify and prioritize security risks to the organization

A risk assessment is a managerial (administrative) control — it involves governance, oversight, and decision-making processes rather than technical or physical implementations. This is the correct answer.

Which of the following is the BEST example of an operational security control?

Answer: Security guards performing regular patrols of a data center facility

Security guards performing patrols are an operational control — they are people following procedures to enforce security. Operational controls are carried out by humans. This is the correct answer.
