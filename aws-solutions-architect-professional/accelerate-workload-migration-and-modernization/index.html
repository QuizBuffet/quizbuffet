4.0 Accelerate Workload Migration and Modernization SAP-C02 Practice Quiz

120 exam-style questions covering 20% of the SAP-C02 exam. Instant feedback on every answer, progress tracking, no signup required.

This domain is part of the AWS Certified Solutions Architect Professional practice test. Each question is tagged by exam objective and difficulty so you can drill exactly the areas you need.

Sample Questions

A financial services company must migrate regulated workloads while keeping audit evidence and rollback options. The team must improve the migration and modernization plan around migration assessment and readiness. What should the solutions architect recommend?
  • A. Classify each workload by an appropriate migration strategy such as rehost, replatform, refactor, repurchase, retire, retain, or relocate
  • B. Use Application Load Balancer connection draining set to zero seconds for stateful sessions
  • C. Use AWS Systems Manager Run Command without Change Manager for production changes
  • D. Use IAM password policy to enforce VPC routing decisions

The migration strategy should fit the workload's constraints, value, and modernization opportunity.

A public sector agency is replacing aging infrastructure with a governed AWS landing zone. The team must improve the migration and modernization plan around migration strategies. What should the solutions architect recommend?
  • A. Use a structured portfolio assessment that captures business criticality, dependencies, technical complexity, compliance needs, and migration readiness
  • B. Use Secrets Manager without rotation to reduce operational complexity
  • C. Use AWS Cost Explorer to provision EC2 capacity in advance
  • D. Skip log retention policies and keep all CloudWatch Logs forever

A migration portfolio should be prioritized from evidence about business value, dependency risk, and technical readiness.

A media company needs to migrate large content repositories and modernize delivery workflows. A review board asks for a professional-level recommendation for migration assessment and readiness. Which option best fits the workload?
  • A. Place customer gateway IP inside the VPC CIDR range
  • B. Group workloads into migration waves based on dependency maps, business windows, risk, team readiness, and shared platform prerequisites
  • C. Use a single AWS Cost and Usage Report at the account level for an organization with 200 accounts
  • D. Use ACM-imported public certs without renewal monitoring or alerting

Wave planning reduces cutover risk by moving related components in a controlled sequence.

A logistics company needs to migrate databases and integrations with minimal downtime. A review board asks for a professional-level recommendation for migration strategies. Which option best fits the workload?
  • A. Use Reserved Instances purchased for one Region to cover usage in a different Region
  • B. Use AWS Application Discovery Service, Migration Evaluator, stakeholder interviews, and dependency mapping to build the migration inventory
  • C. Use AWS Budgets to enforce IAM permission boundaries on engineering teams
  • D. Use AWS Pricing Calculator as a real-time bill cap

Discovery must combine tooling and business input to avoid missing dependencies and ownership constraints.

A global enterprise is moving several data center applications to AWS after a portfolio review. Current plans show risk around workload dependencies and constraints. Which decision should be made before the next migration wave?
  • A. Use IAM password policy as the authoritative identity provider for federated users
  • B. Build a migration business case that includes infrastructure savings, licensing effects, operational changes, migration cost, risk reduction, and modernization value
  • C. Use AWS Budgets alarms only for total account spend, never per-service or per-tag
  • D. Use AWS GuardDuty findings without routing them to Security Hub or EventBridge

The business case should compare total value and risk rather than just infrastructure replacement cost.

A retail organization is migrating an order-processing platform before a seasonal peak. Current plans show risk around migration assessment and readiness. Which decision should be made before the next migration wave?
  • A. Disable AWS Shield Standard to reduce baseline latency
  • B. Use AWS Backup without vault lock to satisfy ransomware-resistant retention
  • C. Retain or defer workloads when dependencies, regulations, or business timing make immediate migration higher risk than value
  • D. Use Amazon Cognito identity pools as a replacement for AWS Organizations SCPs

Not every workload should move in the first wave; retained workloads still need a documented rationale.

A SaaS vendor is modernizing a monolithic application into independently deployable services. The target AWS architecture must address application portfolio discovery while reducing migration risk. What is the best recommendation?
  • A. Use Direct Connect public VIFs to reach private VPC subnets during migration
  • B. Treat AWS Organizations consolidated billing as a substitute for SCPs
  • C. Classify each workload by an appropriate migration strategy such as rehost, replatform, refactor, repurchase, retire, retain, or relocate
  • D. Use simple scaling policies with cool-downs longer than the spike duration for traffic bursts

The migration strategy should fit the workload's constraints, value, and modernization opportunity.

A manufacturing company is moving plant applications to AWS while some factory systems remain on premises. Leadership wants a modernization approach that is measurable and low risk for migration strategies. Which action is most appropriate?
  • A. Use AWS DataSync to provide live SQL replication between two RDS Aurora clusters
  • B. Use Amazon DynamoDB for relational workloads requiring multi-table joins and complex transactions
  • C. Use AWS Control Tower without enrolling existing accounts to skip baseline controls
  • D. Build a migration business case that includes infrastructure savings, licensing effects, operational changes, migration cost, risk reduction, and modernization value

The business case should compare total value and risk rather than just infrastructure replacement cost.
