Sample Questions

Which type of cryptography uses a single shared secret key for both the encryption and decryption of data?

Answer: Symmetric encryption

Symmetric encryption uses one shared secret key for both encrypting plaintext and decrypting ciphertext. Both the sender and receiver must securely exchange and protect this single key. Common symmetric algorithms include AES, 3DES, Blowfish, and ChaCha20. The primary challenge is secure key distribution — if the key is intercepted, all encrypted communications are compromised.

Which widely deployed open-source cryptographic toolkit provides a full implementation of the SSL and TLS protocols and includes command-line utilities for key generation, certificate management, hashing, and encryption?

Answer: OpenSSL

OpenSSL is the de facto standard open-source cryptographic library and command-line toolkit, providing implementations of SSL/TLS protocols and a broad range of cryptographic functions. It is used by the majority of HTTPS web servers (via Apache, Nginx, and others), provides the libssl and libcrypto libraries, and offers command-line tools for RSA/ECC key generation, X.509 certificate creation and signing, S/MIME, PKCS operations, and symmetric encryption/decryption.

In a Public Key Infrastructure (PKI), which entity is specifically responsible for digitally signing and issuing certificates that cryptographically bind a public key to an identity?

Answer: Certificate Authority (CA) — signs and issues certificates binding public keys to verified identities

The Certificate Authority (CA) is the trusted third party at the heart of PKI. The CA uses its own private key to digitally sign X.509 certificates, cryptographically binding a subject's public key to their identity (name, organization, domain). This signature allows relying parties (browsers, TLS clients) to verify that the certificate was issued by a trusted CA without directly contacting the CA for each transaction.
