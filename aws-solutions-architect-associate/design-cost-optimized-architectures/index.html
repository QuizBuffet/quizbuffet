Key Terms in This Domain

  • Amazon S3 Glacier: Low-cost archival object storage for long-term retention
  • AWS Fargate: Serverless compute engine for containers (ECS/EKS)
  • Amazon EBS: Persistent block storage volumes for EC2 instances
  • AWS Storage Gateway: Hybrid cloud storage: give on-prem apps access to AWS storage
  • Amazon Athena: Query data in S3 with standard SQL, serverless
  • AWS Glue: Serverless ETL: discover, catalog, and transform data
  • Amazon EventBridge: Serverless event bus connecting AWS, SaaS, and custom apps
  • AWS Step Functions: Serverless workflow orchestration with visual state machines
  • AWS Budgets: Set custom cost or usage budgets and alert on overruns
  • AWS Cost and Usage Report: Most detailed cost data: granular line-item billing exports
