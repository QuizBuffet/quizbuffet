Key Terms in This Domain

  • AWS Elastic Disaster Recovery: Continuous replication and failover for on-prem and AWS workloads
  • ECS/EKS Anywhere: Run ECS/EKS on customer-managed infrastructure (on-prem, edge)
  • RTO / RPO: Recovery time and recovery point objectives drive DR strategy choice
  • Backup and restore: Lowest-cost DR pattern; restores from backups on disaster
  • Application Recovery Controller: Coordinates failover for multi-Region applications
  • AWS Application Migration Service: Lift-and-shift rehosting via continuous block-level replication (MGN)
  • AWS Trusted Advisor: Best-practice checks across cost, performance, security, and limits
  • AWS CodeDeploy: Automated application deployment to compute services
  • AWS Organizations: Multi-account management with consolidated billing and policies
  • Control Tower controls: Mandatory, strongly recommended, and elective guardrails for landing zones
