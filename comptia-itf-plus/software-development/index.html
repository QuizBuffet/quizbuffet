Sample Questions

Which statement best defines Interpreted programming languages?
  • A. Interpreted programming languages are executed by an interpreter at run time rather than being fully converted into a standalone machine-code executable before execution. Python or JavaScript code is commonly run by a runtime/interpreter rather than shipped only as a precompiled executable.
  • B. Compiled programming languages: Compiled programming languages are translated into machine code before execution, typically producing an executable or build artifact.
  • C. Markup languages: Markup languages describe document structure or presentation rather than general program execution.
  • D. Assembly language: Assembly language uses low-level mnemonics closely tied to processor instructions.

Interpreted programming languages is the tested concept. Interpreted programming languages are executed by an interpreter at run time rather than being fully converted into a standalone machine-code executable before execution. This is the correct answer.

Which statement best defines Scripting languages?
  • A. Compiled programming languages: Compiled programming languages are commonly used for applications that are built into executable programs before being run.
  • B. Scripting languages are commonly used to automate tasks, glue systems together, and run commands through an interpreter or runtime environment. A script that renames files, configures a system, or automates a browser task is using a scripting language approach.
  • C. Query languages: Query languages retrieve or modify data in databases rather than automate operating system or application tasks.
  • D. Markup languages: Markup languages structure content and are not primarily used to automate procedures.

Scripting languages is the tested concept. Scripting languages are commonly used to automate tasks, glue systems together, and run commands through an interpreter or runtime environment. This is the correct answer.
