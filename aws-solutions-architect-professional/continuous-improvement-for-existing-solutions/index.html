Sample Questions

A healthcare SaaS provider has passed initial launch and is remediating findings from a Well-Architected review. A post-incident review identifies alerting and automatic remediation strategies as the highest-value improvement area. Which recommendation is most appropriate?
  • A. Centralize application, infrastructure, and audit logs in CloudWatch Logs or Amazon S3 with retention, query, and ownership standards
  • B. Use AWS Inspector findings without prioritizing critical CVEs
  • C. Use Application Load Balancer connection draining set to zero seconds for stateful sessions
  • D. Use a single CloudWatch alarm threshold across every workload regardless of baseline

A centralized logging strategy makes operational events searchable and consistent across accounts and services.

A public sector agency is improving a citizen-services application after a recent incident. A post-incident review identifies disaster recovery planning as the highest-value improvement area. Which recommendation is most appropriate?
  • A. Create CloudWatch alarms with EventBridge rules and Systems Manager Automation runbooks for well-understood failure modes
  • B. Use general-purpose gp2 EBS for a workload requiring sustained 60K IOPS
  • C. Use AWS Service Catalog as a packet-inspection firewall
  • D. Use Amazon Cognito identity pools as a replacement for AWS Organizations SCPs

Automated alerting and remediation reduce time to detect and repair repeatable operational issues.

A financial services workload has audit findings, rising costs, and several manual operational processes. The existing solution meets basic requirements but has operational gaps around alerting and automatic remediation strategies. Which improvement should be prioritized?
  • A. Continue all-at-once production deployments without rollback criteria
  • B. Use AWS Systems Manager State Manager, Patch Manager, Automation, and Parameter Store to standardize configuration management
  • C. Allow public S3 ACLs for any bucket that serves static content
  • D. Allow encryption keys to be unmanaged by KMS so any service can decrypt the data

Systems Manager can enforce configuration state and automate operational tasks across fleets.

A gaming company is improving latency, reliability, and operations for an existing backend. The existing solution meets basic requirements but has operational gaps around disaster recovery planning. Which improvement should be prioritized?
  • A. Use Amazon EBS snapshots as a substitute for a multi-Region Aurora Global Database
  • B. Move from all-at-once releases to blue/green, canary, or rolling deployments with health checks and automated rollback
  • C. Disable rollback in CloudFormation so partial deploys remain in place for debugging
  • D. Use AWS Cost Explorer to provision EC2 capacity in advance

Safer deployment strategies reduce the blast radius of failed changes.

A global insurance company already runs a multi-account AWS platform and wants to improve it without rebuilding from scratch. A post-incident review identifies CI/CD pipelines and deployment strategies as the highest-value improvement area. Which recommendation is most appropriate?
  • A. Use AWS Systems Manager Run Command without Change Manager for production changes
  • B. Run game days and failure-injection exercises that validate documented recovery actions and update runbooks afterward
  • C. Use IAM roles in place of resource policies for cross-account S3 access
  • D. Use IAM session policies to expand a role beyond its attached permissions

Failure exercises reveal gaps in recovery procedures before real incidents occur.

A manufacturing company is standardizing operational practices across several AWS accounts. A Well-Architected review requires a practical improvement strategy for alerting and automatic remediation strategies. What should be recommended?
  • A. Use IAM password policy as the authoritative identity provider for federated users
  • B. Use Amazon Route 53 Resolver DNS Firewall to authenticate API Gateway requests
  • C. Prioritize automation for frequent, high-risk, and high-toil operational tasks before automating rare or poorly understood exceptions
  • D. Use AWS Auto Scaling without scaling cooldowns or step policies for spike-prone workloads

Automation investment should target recurring operational pain with clear success criteria.

A logistics platform team is reviewing production telemetry from a distributed AWS workload. The platform team wants measurable improvement for monitoring and logging solutions without a full rebuild. Which action best fits the goal?
  • A. Skip cross-account event notifications and rely on per-account email subscriptions
  • B. Skip enabling S3 Intelligent-Tiering for unpredictable access patterns to keep object listings simpler
  • C. Centralize application, infrastructure, and audit logs in CloudWatch Logs or Amazon S3 with retention, query, and ownership standards
  • D. Use Service Control Policies to grant additional permissions beyond IAM

A centralized logging strategy makes operational events searchable and consistent across accounts and services.

A retail enterprise is preparing for a seasonal event and wants to improve an existing solution. The fraud detection workload is already in production, and the team must improve disaster recovery planning. What should the solutions architect recommend?
  • A. Use Network ACLs as a stateful application-layer firewall
  • B. Use Amazon CloudWatch metrics without alarms or dashboards in production
  • C. Use Multi-AZ RDS as a sufficient disaster recovery strategy across Regions
  • D. Run game days and failure-injection exercises that validate documented recovery actions and update runbooks afterward

Failure exercises reveal gaps in recovery procedures before real incidents occur.

Key Terms in This Domain

  • AWS Elastic Disaster Recovery: Continuous replication and failover for on-prem and AWS workloads
  • AWS Trusted Advisor: Best-practice checks across cost, performance, security, and limits
  • Amazon Aurora: High-performance MySQL/PostgreSQL-compatible cloud database
  • Backup and restore: Lowest-cost DR pattern; restores from backups on disaster
  • AWS Cost Explorer: Visualize, understand, and forecast costs and usage
  • AWS Budgets: Set custom cost and usage budgets with alerts
  • AWS Cost and Usage Report: Granular billing data delivered to S3 for analysis
  • S3 Storage Lens: Org-wide visibility into S3 usage and activity for cost optimization
  • AWS Organizations: Multi-account management with consolidated billing and policies
  • AWS Systems Manager: Operations management, automation, and config across resources at scale
