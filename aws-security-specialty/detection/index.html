Sample Questions

A payment API handles cardholder-adjacent metadata and is exposed through API Gateway and Lambda. The security team needs near-real-time detection of suspicious access patterns and failed authorization. Which monitoring requirement should be prioritized?

Answer: Capture API access logs, Lambda application errors, authentication outcomes, and security findings with alerting on abnormal patterns

The workload includes an internet-facing API and sensitive transaction context, so monitoring must cover request activity, application failures, authentication behavior, and security findings together.

A workload processes confidential documents and stores them in S3. The team must detect accidental exposure and sensitive data placement. What monitoring requirement is most relevant?

Answer: Monitor S3 public access changes, object-level activity where required, and Amazon Macie findings

Confidential document monitoring should include exposure detection, object access visibility, and sensitive data discovery.

A Lambda-based API has intermittent downstream timeouts. What monitoring strategy should be implemented?

Answer: Track Lambda errors, duration, throttles, downstream dependency latency, and correlation IDs

Timeout diagnosis requires function health, dependency timing, and request correlation across the path.
