About this certification

The Google Cybersecurity Professional Certificate is a self-paced, course-based credential delivered through Coursera. It covers cybersecurity fundamentals, security frameworks and controls, network security, Linux and SQL for security, asset protection, incident detection and response, and Python for security automation. Completion is based on graded assignments — there is no proctored exam. Aligned to entry-level SOC analyst and cybersecurity analyst roles, and counts as preparation for CompTIA Security+ which remains the industry-standard exam.
