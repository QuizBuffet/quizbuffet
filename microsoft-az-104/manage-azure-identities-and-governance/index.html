Key Terms in This Domain

  • Microsoft Entra ID: Cloud-based identity and access management (formerly Azure AD)
  • Microsoft Entra Connect: Sync on-premises AD identities to Microsoft Entra ID
  • Entra ID group: Security or Microsoft 365 group used for access and licensing
  • Microsoft Entra license: P1/P2 features attached per user (Conditional Access, PIM, etc.)
  • Resource group: Logical container for Azure resources sharing lifecycle and policies
  • Azure Budget: Spend threshold with alerts via action groups
  • Move resource: Move VMs between resource groups, subscriptions, or regions
  • Azure Resource Manager (ARM): Deployment and management layer for Azure resources
  • Deployment scope: Resource group, subscription, management group, or tenant
  • Entra ID user: Cloud, guest (B2B), or synchronized identity
