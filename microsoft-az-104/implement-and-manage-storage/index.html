Sample Questions

A production storage account must be updated for configure Azure Storage firewalls and virtual networks. Which administrative action best fits the requirement?

Answer: Set the storage account network access to selected networks and add the required virtual network subnet or trusted public IP range

Storage account firewall rules restrict access to approved networks while allowing required clients to connect.

A storage-related support ticket requires action for configure Azure Storage firewalls and virtual networks. Which implementation is most appropriate?

Answer: Verify DNS resolution to the private endpoint when clients cannot reach a storage account after public access is disabled

Private endpoint connectivity depends on clients resolving the storage account name to the private endpoint address.

During an Azure Storage review, the team identifies a requirement for create and use shared access signature tokens. What should be done?

Answer: Generate a service SAS when access is needed to a specific blob, container, queue, table, or file resource

A service SAS delegates access to a specific Azure Storage service resource.
