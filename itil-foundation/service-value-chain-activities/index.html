5.0 Service Value Chain Activities ITIL 4 Practice Quiz

20 exam-style questions covering 5% of the ITIL 4 exam. Instant feedback on every answer, progress tracking, no signup required.

This domain is part of the ITIL 4 Foundation practice test. Each question is tagged by exam objective and difficulty so you can drill exactly the areas you need.

Sample Questions

Which statement best describes the service value chain?
  • A. An operating model for the creation, delivery, and continual improvement of services
  • B. A fixed sequence of activities that every value stream must follow exactly
  • C. A list of only technical support practices
  • D. A replacement for the guiding principles and practices

The service value chain is the central operating model for creating, delivering, and continually improving services. This is the correct answer.

Which statement about interconnected nature of the service value chain is CORRECT?
  • A. Different types of demand and opportunity require different combinations of activities
  • B. Because service providers should avoid planning work
  • C. Because continual improvement is outside the service value system
  • D. Because the activities are unrelated to one another

The service value chain is flexible so organizations can create value streams suited to different needs. This is the correct answer.

How do service value chain activities support value streams?
  • A. They are used only when a new service is created
  • B. They can be combined in different ways to create value streams for specific situations
  • C. They remove the need to understand demand
  • D. They must always be used once each in the same order

Value streams use service value chain activities in patterns that fit the required outcome. This is the correct answer.

Which output is commonly associated with the plan activity?
  • A. User support interactions
  • B. Strategic, tactical, and operational plans or portfolio decisions
  • C. Resolved incidents from live services
  • D. New or changed service components

Plan produces direction and plans that guide service value chain work. This is the correct answer.

What is the purpose of the improve activity in the service value chain?
  • A. To receive stakeholder demand and convert it into requirements
  • B. To ensure continual improvement of products, services, and practices across all value chain activities and the four dimensions
  • C. To build every service component used by the organization
  • D. To authorize budget for service consumption

Improve ensures continual improvement across services, practices, activities, and dimensions. This is the correct answer.

Identify the missing word(s): The relevant service value chain activity or concept is [?]. Which statement about the service value chain activities is CORRECT?
  • A. The activities are the same as the four dimensions
  • B. Each activity works independently with no shared inputs or outputs
  • C. Each activity transforms inputs into outputs and can receive or provide work to other activities
  • D. The activities apply only to service providers that use automation

The activities are interconnected and exchange inputs and outputs to enable value creation. This is the correct answer.

What is the purpose of the plan activity in the service value chain?
  • A. To make services available for use by users
  • B. To obtain service components from suppliers or build them internally
  • C. To ensure a shared understanding of the vision, current status, and improvement direction for all four dimensions and all products and services
  • D. To provide a channel for stakeholder communication

Plan ensures shared understanding of direction, status, and improvement across the organization. This is the correct answer.

A team maps how demand becomes value through several connected activities. Which concept are they applying?
  • A. A warranty target only
  • B. A single supplier contract
  • C. A service relationship role definition
  • D. A value stream using service value chain activities

A value stream describes how activities combine to create value for a specific scenario. This is the correct answer.

Key Terms in This Domain

  • Service Value Chain (SVC): Operating model for service providers describing six key interconnected activities
  • Partners and suppliers: Dimension covering relationships with third parties involved in service design, delivery, support, and use
  • Improve (SVC activity): Ensures continual improvement of products, services, and practices across the value chain
  • Service relationship management: Joint activities between provider and consumer to ensure continual value co-creation
  • Value streams and processes: Dimension covering the activities, workflows, controls, and procedures needed to achieve agreed objectives
  • Value stream: A series of steps an organization takes to create and deliver products and services to consumers
  • Service Value System (SVS): How all components and activities of an organization work together to facilitate value creation through IT-enabled services
  • Plan (SVC activity): Ensures shared understanding of vision, current status, and improvement direction across all four dimensions
  • Design and transition (SVC): Ensures products and services continually meet stakeholder expectations for quality, costs, and time-to-market
  • Obtain/build (SVC activity): Ensures service components are available when and where needed, meeting agreed specifications
