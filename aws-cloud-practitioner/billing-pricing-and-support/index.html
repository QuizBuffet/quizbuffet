Key Terms in This Domain

  • AWS Budgets: Set custom cost or usage budgets and alert on overruns
  • AWS Cost and Usage Reports: Most detailed cost data: granular line-item billing exports
  • AWS Cost Explorer: Visualize and forecast AWS spend by service, account, or tag
  • AWS Marketplace: Curated catalog of third-party software and SaaS purchasable through AWS billing
  • AWS Support: Tiered customer support: Developer, Business, Enterprise On-Ramp, Enterprise
  • AWS Auto Scaling: Automatically scale resources up and down to match demand
  • AWS Organizations: Centrally manage and govern multiple AWS accounts with consolidated billing
  • AWS Trusted Advisor: Best-practice checks for cost, performance, security, fault tolerance, service limits
  • AWS Direct Connect: Dedicated private network connection from on-premises to AWS
  • AWS Artifact: On-demand access to AWS compliance reports (SOC, ISO, PCI, etc.)
