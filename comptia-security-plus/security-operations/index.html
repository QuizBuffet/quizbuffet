Sample Questions

What is a secure baseline and what three activities are required to maintain it?

Answer: A secure baseline is a documented, approved security configuration standard for a system type — defining required settings for OS hardening, services, accounts, network configuration, and security controls. Three required activities: (1) Establish — define the baseline by selecting a security framework (CIS Benchmarks, DISA STIGs, vendor hardening guides) and customizing for the organization's requirements; (2) Deploy — apply the baseline consistently to all instances of that system type through automation (GPO, Ansible, Chef, Puppet, golden images); (3) Maintain — continuously monitor for configuration drift from the baseline using compliance scanning tools and remediate deviations

Establish, deploy, and maintain are the three lifecycle activities for secure baselines — each is required for effective baseline management. This is the correct answer.

What are the key security hardening measures for corporate mobile devices (smartphones and tablets)?

Answer: Key mobile device hardening measures: enable full-device encryption (FileVault equivalent for mobile); enforce PIN/biometric lock with short auto-lock timeout; MDM enrollment enabling remote wipe if lost or stolen; disable developer mode and USB debugging; restrict app installation to approved apps or corporate app store; enable automatic OS and app updates; configure VPN for corporate network access; disable Bluetooth and WiFi auto-connect to unknown networks; enable remote locate/wipe; and configure certificate-based email and application authentication

Mobile device hardening spans encryption, authentication, MDM controls, network security, and update management — a comprehensive approach. This is the correct answer.

What are the essential security hardening steps for corporate Windows workstations?

Answer: Essential Windows workstation hardening: remove local administrator rights for standard users; enable full-disk encryption (BitLocker); deploy endpoint protection (EDR); configure Windows Firewall (host-based firewall enabled, default deny inbound); disable unused services and features (telnet, SMBv1, AutoRun, PowerShell v2); enforce Group Policy for security settings (screen lock timeout, password policy, audit logging); apply application allowlisting or at minimum block execution from user-writable directories; keep OS and applications patched; enable Windows Defender Credential Guard to protect credentials; configure LAPS for unique local administrator passwords; and disable USB storage if not needed

Workstation hardening spans account privilege, encryption, endpoint protection, service reduction, policy enforcement, patching, and credential protection — a comprehensive set. This is the correct answer.
