Key Terms in This Domain

  • Subscription: Billing and access boundary in Azure containing resource groups
  • Azure Storage Explorer: Free GUI for managing Azure Storage resources
  • Azure RBAC: Role-based access control for Azure resources
  • Azure region pair: Two regions paired in the same geography for resilience
  • Sovereign region: Region designed for government or regulated workloads (e.g., Azure Government)
  • Azure Resource Manager (ARM): Deployment and management layer for Azure resources
  • Resource group: Logical container for Azure resources sharing lifecycle and policies
  • Azure Virtual Machines: IaaS Windows or Linux VMs in Azure
  • Azure Disk Storage: Managed disks attached to Azure VMs (SSD/HDD options)
  • Azure Policy: Define and enforce rules on Azure resources for compliance
