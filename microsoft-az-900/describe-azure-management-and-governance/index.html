A business team is reviewing Azure operations. Which option correctly describes factors that affect Azure costs?
  • A. Resource type, usage amount, region, purchasing options, and data transfer can all affect Azure costs
  • B. Assume high availability is the same as disaster recovery
  • C. Disable activity logs in production to reduce storage cost
  • D. Use Azure Virtual Machines for a stateless web app that should scale to zero with no traffic

Azure charges vary based on what is deployed, where it runs, how much it is used, and how it is purchased.

A company is learning Azure management and governance. Which statement best describes factors that affect Azure costs?
  • A. Service tiers and performance levels can change the price of Azure resources
  • B. Configure MFA only after a security incident has already occurred
  • C. Choose hybrid cloud only when no on-premises infrastructure exists
  • D. Use Azure Virtual Desktop to host headless server workloads at scale

Higher performance or premium tiers often cost more than basic tiers.

A project team needs to understand factors that affect Azure costs. Which answer matches Azure fundamentals?
  • A. Use Azure Kubernetes Service for a single-container hello-world experiment
  • B. Running resources for longer periods generally increases consumption-based cost
  • C. Treat Azure ExpressRoute as a backup VPN tunnel for site-to-site connectivity
  • D. Use Cost Management to deploy infrastructure code

Many Azure services bill based on usage over time.

  • A. Use the cloud free tier to host long-term production workloads
  • B. The Pricing calculator estimates the cost of Azure services before deployment
  • C. Treat Azure Policy as an alert system rather than an enforcement mechanism
  • D. Skip tagging because Azure already groups resources by their resource group

The Pricing calculator helps estimate the monthly cost of selected Azure resources.

  • A. Use a single global admin account shared by every team member to simplify access
  • B. The two calculators answer different cost-planning questions
  • C. Use Azure Spot VMs for stateful database workloads requiring zero downtime
  • D. Use Azure RBAC permissions on a subscription to grant access only at the resource group level

One estimates Azure service pricing, and the other compares broader on-premises and cloud costs.

  • A. Use a single broad RBAC role for every team member to simplify onboarding
  • B. Use Azure Monitor metrics alone without alarms in production
  • C. Different Azure regions can have different prices for the same service
  • D. Treat Microsoft Entra ID as just a password directory

Regional pricing can affect overall cost planning.

A business team is reviewing Azure operations. Which option correctly describes Pricing calculator and TCO Calculator?
  • A. Use Azure Advisor as a real-time intrusion detection engine
  • B. Use the public internet as the default path for VM-to-VM traffic across two VNets in the same region
  • C. The TCO Calculator estimates savings from moving on-premises workloads to Azure
  • D. Use NSG flow logs as a substitute for application access logs

The TCO Calculator compares current datacenter costs with projected Azure costs.

A cloud adoption team is comparing Azure management options. Which statement about factors that affect Azure costs is accurate?
  • A. Choose a single cloud model for every workload regardless of compliance and latency requirements
  • B. Treat consumption-based pricing as a fixed-fee subscription independent of usage
  • C. Treat reliability and availability as the same metric
  • D. Outbound data transfer and network traffic patterns can affect monthly charges

Data transfer can be a cost factor when services communicate across boundaries or to users.

Key Terms in This Domain

  • Azure Pricing Calculator: Estimate costs for planned Azure deployments
  • Microsoft Cost Management: Cost analysis, budgets, and recommendations for Azure spend
  • Azure Resource Manager (ARM): Deployment and management layer for Azure resources
  • Microsoft Entra ID: Cloud-based identity and access management (formerly Azure AD)
  • Azure Policy: Define and enforce rules on Azure resources for compliance
  • Azure Advisor: Personalized best-practice recommendations across cost, security, performance
  • Azure portal: Web-based unified console for managing Azure resources
  • TCO Calculator: Total Cost of Ownership comparison for on-prem vs Azure
  • Consumption-based pricing: Pay only for resources you use, with no upfront capital cost
  • Resource group: Logical container for Azure resources sharing lifecycle and policies
