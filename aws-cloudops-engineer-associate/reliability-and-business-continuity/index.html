Key Terms in This Domain

  • Amazon EFS: Managed elastic file system shared across compute
  • Amazon FSx: Managed third-party file systems (Windows, Lustre, NetApp ONTAP, OpenZFS)
  • Amazon RDS: Managed relational database service
  • Amazon Aurora: High-performance MySQL/PostgreSQL-compatible managed database
  • Amazon DynamoDB: Managed key-value and document NoSQL database
  • Systems Manager Run Command: Run commands or scripts on managed instances at scale
  • Multi-Region deployment: Spread resources across Regions for disaster recovery and latency
  • Amazon Managed Grafana: Fully managed Grafana for metrics dashboards
  • Amazon Managed Service for Prometheus: Managed Prometheus-compatible metrics for containerized workloads
  • Amazon EventBridge: Serverless event bus that routes, enriches, and delivers events
