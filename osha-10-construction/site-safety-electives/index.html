Sample Questions

Which condition makes a scaffold unsafe to use?

Answer: Missing guardrails, incomplete planking, or unstable support

Scaffolds need proper support, platforms, access, and fall protection to be used safely. This is the correct answer.

What should a worker do if a scaffold appears damaged?

Answer: Stay off it and report the condition

Workers should not use a scaffold that appears unsafe. This is the correct answer.

Which scaffold practice is unsafe?

Answer: On site, climbing cross braces instead of using a proper access point

Cross braces are not intended as safe access routes. This is the correct answer.
