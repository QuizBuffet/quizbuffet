2.0 Incident Response — SCS-C03 Practice Quiz

This domain is part of the AWS Certified Security – Specialty practice test. Each question is tagged by exam objective and difficulty so you can drill exactly the areas you need.

Sample Questions

A GuardDuty finding indicates possible EC2 credential exfiltration. The security team wants a repeatable plan that analysts can execute consistently. What should the runbook define first?

Answer: Triage steps, severity criteria, affected-resource identification, containment actions, and evidence preservation

A useful incident runbook starts by turning the finding into a scoped, prioritized workflow that preserves evidence before destructive changes occur.

A team uses Systems Manager OpsCenter for incident work. What should a security incident response plan specify?

Answer: How findings create OpsItems, required context fields, assignment, escalation, and linked automation documents

OpsCenter is most effective when incident intake, ownership, context, and automation links are defined before incidents occur.

A response plan for suspected data exfiltration needs a decision point for customer notification. What should the runbook capture before that decision?

Answer: Confirmed data types, affected resources, access path, time window, identities, and legal or compliance contacts

Notification decisions require scoped evidence about what data was accessed, how, when, and who must be involved.
