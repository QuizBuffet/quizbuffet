Key Terms in This Domain

  • AWS Artifact: On-demand access to AWS compliance reports (SOC, ISO, PCI, etc.)
  • AWS Audit Manager: Continuously audit AWS usage against compliance frameworks
  • AWS Security Hub: Single dashboard aggregating security alerts and compliance status
  • Amazon Redshift: Petabyte-scale managed data warehouse
  • Amazon Connect: Cloud-based contact center for customer service
  • AWS Support: Tiered customer support: Developer, Business, Enterprise On-Ramp, Enterprise
  • Amazon SageMaker AI: End-to-end platform to build, train, and deploy ML models
  • AWS Config: Track configuration changes and compliance of AWS resources
  • AWS License Manager: Manage software licenses across AWS and on-premises
  • AWS Systems Manager: Operational hub: patch, automate, and configure AWS and on-prem resources
