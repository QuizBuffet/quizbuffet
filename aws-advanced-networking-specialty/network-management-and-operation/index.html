Key Terms in This Domain

  • Amazon VPC: Logically isolated virtual network for AWS resources
  • Elastic Network Interface (ENI): Virtual NIC with IPs, MAC, and security groups, attachable to EC2
  • Network ACL: Stateless subnet-level firewall with allow and deny rules
  • AWS Transit Gateway: Hub for connecting VPCs and on-premises networks at scale
  • Transit Gateway Network Manager: Topology, events, and metrics across global AWS networks
  • AWS Cloud WAN: Managed global wide-area network with central policy
  • AWS Organizations: Multi-account management with consolidated billing and policies
  • AWS Global Accelerator: Static anycast IPs that route over the AWS global network to nearest endpoint
  • Network Load Balancer: Layer 4 ELB for ultra-low latency TCP/UDP/TLS, static IPs, PrivateLink
  • Gateway Load Balancer: Layer 3/4 ELB using GENEVE for inline third-party network appliances
