Sample Questions

A public application behind an ALB receives HTTP floods and SQL injection attempts. Which control should be placed at the edge or load balancer path?

Answer: AWS WAF with managed rules, rate-based rules, and logging for the web ACL

AWS WAF can inspect HTTP requests, block common web exploits, rate-limit abusive clients, and provide rule-level logs.

A public API needs throttling and request validation before traffic reaches private services. Which service combination is appropriate?

Answer: Amazon API Gateway with authorizers, throttling, AWS WAF, and private integration as needed

API Gateway and AWS WAF can enforce web request controls while keeping backend services private.

Private subnets need internet access, but all outbound traffic must be inspected and logged. What should be used?

Answer: Centralized egress through AWS Network Firewall or proxy appliances with route-table steering

Outbound filtering requires traffic to pass through an inspection layer before internet egress.
