Sample Questions

Which statement best describes the purpose of the ITIL service value system?
  • A. It describes how all components and activities of the organization work together as a system to enable value creation
  • B. It provides a list of mandatory process steps for every incident
  • C. It defines the exact technology architecture required for every service provider
  • D. It replaces the need for practices, governance, and continual improvement

The service value system shows how organizational components and activities work together to facilitate value creation. This is the correct answer.

Which statement about the ITIL service value system component is CORRECT? How do guiding principles support the service value system?
  • A. They guide decisions and actions across all components and activities of the organization
  • B. They replace the need for governance
  • C. They apply only to continual improvement activities
  • D. They define every workflow step in the service value chain

Guiding principles influence how the organization makes decisions and acts across the SVS. This is the correct answer.

Which are components of the ITIL service value system?
  • A. Organizations and people; information and technology; partners and suppliers; value streams and processes
  • B. Guiding principles, governance, service value chain, practices, and continual improvement
  • C. Incident, problem, change, service request, and service desk
  • D. Utility, warranty, customer, user, and sponsor

The service value system includes guiding principles, governance, the service value chain, practices, and continual improvement. This is the correct answer.

Which statement about the ITIL service value system component is CORRECT? How does governance support the service value system?
  • A. It removes the need for continual improvement
  • B. It directs and controls the organization
  • C. It performs every service desk activity
  • D. It is the same as a supplier relationship

Governance directs and controls the organization so it can create value and meet objectives. This is the correct answer.

An organization receives demand for a new service and identifies an opportunity to improve customer experience. Which ITIL concept explains how these inputs are converted into value?
  • A. The definition of a user
  • B. The ITIL service value system
  • C. A warranty target
  • D. A single supplier contract

The service value system explains how opportunity and demand are transformed into value through its components and activities. This is the correct answer.

Identify the missing word(s): In the ITIL service value system, the main input is [?]. What is the main input to the ITIL service value system?
  • A. Suppliers and technology
  • B. Outputs and warranty
  • C. Opportunity and demand
  • D. Practices and processes

Opportunity and demand are the main inputs to the service value system. This is the correct answer.

Which statement about the ITIL service value system component is CORRECT? What is the role of the service value chain in the service value system?
  • A. It defines the four dimensions of service management
  • B. It authorizes budget for service consumption
  • C. It provides an operating model for the creation, delivery, and continual improvement of services
  • D. It describes only the service desk function

The service value chain is the operating model used to create, deliver, and continually improve services. This is the correct answer.

Identify the missing word(s): In the ITIL service value system, the main output is [?]. What is the main output of the ITIL service value system?
  • A. A service desk ticket
  • B. A supplier contract
  • C. A process document
  • D. Value

The service value system turns opportunity and demand into value. This is the correct answer.

Key Terms in This Domain

  • Service Value System (SVS): How all components and activities of an organization work together to facilitate value creation through IT-enabled services
  • Service: A means of enabling value co-creation by facilitating outcomes the customer wants without managing specific costs or risks
  • Service management: A set of specialized organizational capabilities for enabling value for customers in the form of services
  • Value: The perceived benefits, usefulness, and importance of something
  • Service relationship management: Joint activities between provider and consumer to ensure continual value co-creation
  • Value co-creation: Active collaboration of stakeholders (provider and consumer) to produce mutual value
  • Focus on value: Guiding principle: every activity contributes to value for stakeholders
  • Value streams and processes: Dimension covering the activities, workflows, controls, and procedures needed to achieve agreed objectives
  • Value stream: A series of steps an organization takes to create and deliver products and services to consumers
  • Service Value Chain (SVC): Operating model for service providers describing six key interconnected activities
