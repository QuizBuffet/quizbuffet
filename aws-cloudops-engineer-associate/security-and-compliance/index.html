Sample Questions

A company requires console users to use an additional authentication factor before accessing AWS accounts. Which IAM feature should be enforced?

Answer: Multi-factor authentication

Multi-factor authentication. AWS designs this control specifically for IAM features use cases.

An operations team needs workforce users to access multiple AWS accounts through centralized federation. Which service should be considered?

Answer: AWS IAM Identity Center

AWS IAM Identity Center. This is the textbook AWS pattern for IAM features.

A developer receives AccessDenied when calling an AWS API. Which tool can simulate whether the developer's policies allow the action?

Answer: IAM policy simulator

IAM policy simulator. AWS designs this control specifically for Access troubleshooting and auditing use cases.
